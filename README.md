網站：https://prayer168.github.io/ai-science-evidence-inquiry/

## 已提供

- 「關於科學探究」：10個內容區塊、互動循環圖、CER、完整溶解案例（模擬數據）與5份 Markdown 工具模板。
- 19個完整案例在同一詳解視窗呈現背景、AI流程、證據限制、教學轉化及來源。

- 圖像區分實景、原文圖表、官方示意與網頁教學圖解；沒有宣稱使用 Imagen 2.5。

- 工作台總覽、19 個研究案例、18 項 AI 工具及 5 份探究教案。
- 關鍵字搜尋、分類篩選、原始來源詳情。
- 33 筆工具／案例／教材關聯及節點篩選。
- 瀏覽器本機審核筆記、儲存與 JSON 匯出。
- 響應式版面與鍵盤可操作的原生表單及對話框。

## 功能界線

本版是靜態網站，不具備 PDF 解析、AI 判讀、跨來源撤稿查核、教材自動生成、身分驗證、正式核准或 Science Portal 發布。資料中的查證狀態沿用原始資料，不代表本網站已完成覆核。本機筆記不會傳送伺服器，清除瀏覽器資料會遺失，請使用匯出備份。

## 本機預覽

使用任一靜態 HTTP 伺服器，在此目錄執行，例如已安裝 Python 時：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

瀏覽 http://127.0.0.1:8765。請勿直接雙擊 HTML，資料載入需要 HTTP。

## 核心原則

AI 協助蒐集與分析；教師負責證據判斷；人工核准後才正式發布。AI 信心不能取代研究可信度判斷。

Do not commit API keys, local databases, full-text research PDFs, or personal information.

## 開發與檢查

已安裝 Node.js 時可執行 `npm start` 預覽，`npm run check` 執行語法與內容檢查，不需安裝套件。

`data/case-details.json` 是新增案例敘事及來源；原始 V1.6 資料保留。照片及圖表權利屬原發布者，未授予整個儲存庫的通用再利用授權。

## V1.8.0 三層知識地圖

知識關聯採三層立體圓環：18個工具、19個案例、5份教材，沿用33筆既有關聯。以透視投影與原生按鈕呈現，無額外遠端程式依賴。支援拖曳旋轉、滾輪／按鈕縮放、俯視、重設、全螢幕、深色與柔和底色、平面模式、名稱／類型／分類篩選、節點聚焦與側邊摘要。自動旋轉預設關閉；鍵盤可用Tab選節點、Enter確認，聚焦地圖時可用方向鍵及＋／−。窄螢幕預設平面模式，觸控裝置可雙指縮放3D地圖。圖像外站載入失敗顯示備援圖示，原始照片出處仍在案例詳解。

詳見 docs/VALIDATION-KNOWLEDGE-MAP-V1.8.0.md。不新增自動分頁，不恢復舊大字分頁版。

V1.8.1：知識地圖預設深藍黑底、柔白字與透明文字背景；減少光暈，未關聯節點只降低圖示亮度，名稱保留可讀性。總覽採短名稱，滑鼠移上、鍵盤聚焦或選取顯示完整名稱，側欄始終顯示完整標題。
