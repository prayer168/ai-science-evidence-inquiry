# AI Science Evidence & Inquiry

AI 論文證據分析與科學探究教案生成系統。

## Current status / 目前狀態

This repository currently contains the V1.6 data package and the V1.7 development roadmap. The application source code is not included; this is not yet a runnable system.

目前收錄 V1.6 資料包：19 個案例、18 項工具、5 份教案、33 筆關聯，以及原始 Excel 資料。尚未取得主程式，不能執行安裝或啟動伺服器。資料中的案例與教材不代表已完成研究證據審核。

- `data/`: 原始 JSON 與 Excel 資料。
- `docs/V1.6-original-README.md`: 原資料包說明，保留版本紀錄；其中的安裝指令需要尚未提供的主程式。
- `docs/ROADMAP.md`: V1.7 開發目標與審核流程。

## Principles / 核心原則

AI 協助蒐集與分析；教師負責證據判斷；人工核准後才正式發布。AI 信心不能取代研究可信度判斷。

Do not commit API keys, local databases, full-text research PDFs, or personal information.
