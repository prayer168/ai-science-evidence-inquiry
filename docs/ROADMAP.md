# V1.7 Roadmap

以下為規劃功能，尚未實作。

1. 論文證據工作台：匯入 PDF，依新聞主張找出候選段落、頁碼及圖表，保留原文定位，標示分析理由、信心與不確定性。
2. 跨來源審核閘門：整合 Crossref、OpenAlex、PubMed 撤稿與勘誤資訊；區分查無紀錄、查詢失敗與發現警訊，保存來源及查詢時間。查無紀錄不代表安全保證。
3. 教材草稿生成：依人工核准的證據產生教師研習案例、國小探究學習單及科展研究建議，附來源、限制與人工覆核紀錄。
4. Science Portal：先確認既有三層知識圖譜結構，再串接核准研究與教材，保留版本與發布紀錄。

## Review workflow

匯入論文 → AI 分析 → 跨來源查核 → 教師核准證據 → 生成教材草稿 → 教師核准教材 → 正式發布。

證據或教材內容變更後須重新審核。未核准草稿不得進入正式發布；來源查核不完整時不得自動核准。兩階段核准、查核錯誤處理及權限控制須由後續程式實作與驗證。
