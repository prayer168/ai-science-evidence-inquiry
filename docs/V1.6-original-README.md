# AI 科學探究研究證據中心 V1.6｜教師研究工作台

延續 V1.5：19 個案例、18 項工具、5 份教案、33 筆關聯資料。原本的人工核准、防止未審查發布的保護仍保留。

## 新增能力

1. **PDF 頁碼定位**：只處理審核者合法取得的本機 PDF，使用 PyMuPDF 解析每頁文字、儲存頁次和 SHA-256。PDF 不自動上傳外部 API。支援以文字關鍵字搜尋命中頁面及前後文；**不自動判定研究是否支持新聞主張**。
2. **PubMed 勘誤／撤稿關聯**：按 DOI 查詢 NCBI E-utilities 的 esearch / efetch，讀取 `CommentsCorrections` 及 `PublicationType`。此項為**附加警訊查詢**，尚未併入 V1.5 跨來源核准閘門，人工應同時核對 Crossref/OpenAlex、PubMed 與期刊網頁。未索引、不支援、查詢失敗或查無警訊不能視為安全保證。
3. **三種審核模式**：教師研習、國小探究、科展研究均可儲存經教師確認的獨立備註，有版本歷史；不會自動發布學生或教師備註。
4. **延續逐項新聞查證**：在本機 `/evidence?id=<候選編號>` 檢視研究主張、論文證據與人工審核結果。

## Windows 11 安裝

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m unittest discover -s tests -v
.venv\Scripts\python -m pipeline.cli import fixtures/sample_candidates.json
.venv\Scripts\python -m pipeline.server
```

瀏覽 `http://127.0.0.1:8765`；介面只綁定 127.0.0.1，禁止部署公開網路。

## PDF 匯入與段落搜尋

```powershell
.venv\Scripts\python -m pipeline.cli ingest-pdf 1 "D:\papers\study.pdf" --reviewer "teacher-01"
.venv\Scripts\python -m pipeline.cli locate 1 --query "sample size"
```

文字型 PDF 可擷取；掃描圖片 PDF 若無內嵌文字，僅顯示無文字頁，**不自行 OCR**。PDF 原檔不複製到程式碼倉庫，僅 SQLite 保存擷取文字，因此本機資料庫也應視為受著作權保護及隱私敏感資料並妥善保護。

## PubMed 關聯查詢

```powershell
.venv\Scripts\python -m pipeline.cli pubmed-corrections --doi "10.1000/xyz123"
```

上述 DOI 為格式示例，不代表真實研究。PubMed 查詢需要可用網路、遵循 NCBI 使用頻率限制。**目前尚未與核准前阻擋規則強制整合**。

## 三種模式備註

```powershell
.venv\Scripts\python -m pipeline.cli mode-note 1 --mode elementary --file notes.txt --reviewer "teacher-01"
```

模式：`teacher`（研習）、`elementary`（國小）、`science_fair`（科展）。亦可從本機審核介面保存。

## 安全與限制

- PDF 搜尋是字面詞彙定位，不是語意查證；引文與新聞主張支援程度仍須教師核實。
- 文獻解析器對包含複雜欄位、多欄排版、圖表和掃描頁的文件可能不完整。
- 原研究頁碼以 PDF 第 1 頁起算，可能不等於論文印刷頁碼。
- 已維持 V1.5 核准保護；PubMed 結果尚屬附加來源，不應誤解為已完成三源綜合撤稿審核。
- 正式網站部署、Live API 端對端測試、多使用者身分與審核權限尚未完成。
- 不要將 `pipeline/review.sqlite3`、論文全文或任何個資提交到公開 GitHub。
