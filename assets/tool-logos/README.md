# 工具辨識標誌

各圖原始網址、格式及透明通道檢查保存在 sources.json（2026-10-20）。除 ChatGPT/OpenAI 使用 Simple Icons v11 的 OpenAI 標誌（CC0圖示庫）外，其餘取自官方網站或該網站使用的資產CDN，保持原始形狀與配色。PNG由原始圖示解碼儲存，保留透明通道，SVG保留透明畫布。

GNoME／AlphaEvolve使用Google DeepMind機構圖示；A-Lab使用Berkeley Lab官方正色機構標誌，畫面明確註明機構，並非獨立專案Logo。Colab與Python同列兩個標誌。圖示僅用於辨識連結，不代表合作、授權背書；品牌權利屬原權利人。
